# Keep Believing — Wishes Website

A responsive motivational wishes website with 10 pages, animated transitions, page dots, progress bar, sparkle button, and a final surprise message.

## Files
- `index.html` — website structure
- `style.css` — responsive design and animations
- `script.js` — page content and navigation

## Open on your phone or laptop
1. Extract `keep_believing_wishes.zip`.
2. Open the `keep_believing_wishes` folder.
3. Open `index.html` in Chrome, Firefox, Edge, or another browser.

Internet is only needed for the optional Google Fonts; the website itself works offline with system font fallbacks.

## Publish online with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the published link to appear in Pages.

You can also upload these files to Netlify as a static site.
